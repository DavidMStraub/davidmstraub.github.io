# CAD as Code

*Parametric Modeling and Engineering with Python*

<div class="media">
{{< figure src="/images/cad-as-code-cover.jpg" alt="Cover of CAD as Code" >}}

A textbook on building CAD models as Python programs. It covers modeling techniques, the geometric and topological foundations underneath them, and the workflow around a model: version control, tests, assemblies, data exchange, meshing, finite element simulation and parameter optimization. Twelve chapters with exercises, 121 pages; it assumes basic Python and no prior CAD experience. It grew out of my course on [programming CAx systems](/docs/teaching/) and serves as companion reading for it.

</div>
